# 🌤️ App Clima Chile

Aplicación web desarrollada con Vue.js para consultar información meteorológica de diferentes ciudades de Chile utilizando la API de OpenWeather.

La aplicación permite consultar el clima actual, revisar un pronóstico de 5 días, visualizar estadísticas meteorológicas, guardar ciudades favoritas y configurar preferencias de usuario.
